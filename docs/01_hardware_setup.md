# Hardware Setup

## Device
The project uses an HTC VIVE headset with integrated eye tracking capabilities.

## Objective
To validate and utilize eye tracking data within a Unity-based virtual reality environment.

## General Configuration
- VR headset connected via local network / streaming setup
- Execution through an OpenXR-compatible runtime
- Development performed on a PC

## Considerations
- Connection stability directly impacts tracking quality
- Proper eye tracking calibration is required
