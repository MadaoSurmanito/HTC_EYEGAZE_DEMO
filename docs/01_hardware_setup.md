# Hardware Setup

## Device

The project uses an HTC VIVE headset with integrated eye tracking capabilities.

## Objective

To validate and use eye tracking data inside a Unity-based virtual reality environment, with support for real-time interaction and experimental metric collection.

## General Configuration

- VR headset connected through a local network / streaming setup
- Development performed on a PC
- Execution through an OpenXR-compatible runtime
- Eye tracking data acquired from the headset runtime and consumed inside Unity

## Hardware Requirements

- HTC VIVE headset with eye tracking support
- PC capable of running Unity and VR applications
- Stable local network or streaming connection between headset and PC

## Considerations

- Connection stability directly impacts tracking quality
- Proper eye tracking calibration is required before testing
- Tracking precision may be affected by headset fit, lighting conditions and runtime configuration
- Debugging and metrics collection should be performed only after the hardware setup is stable
