# Eye Tracking Metrics

## Basic Concepts

### Fixations
A period where the gaze remains stable on a point.

### Saccades
Rapid movements between fixations.

## Main Metrics

- FB (Fixations Before): number of fixations before reaching a target
- TFF (Time to First Fixation): time until first fixation
- FD (Fixation Duration): average fixation duration
- TFD (Total Fixation Duration): total time spent looking at a target
- FC (Fixation Count): number of fixations on a target

## Interpretation

- Lower TFF → better visibility
- Higher TFD → greater interest
- Higher FC → more attention
